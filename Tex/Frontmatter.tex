分布式集群是支撑云计算与大数据处理的核心基础设施，其稳定运行直接关系到上层业务的连续性。现有的时序异常检测方法大多聚焦于时间维度和指标维度的二维分析，由于分布式集群任务负载的动态波动，时序指标呈现随机性强、幅度变化大等特点，导致现有方法在多节点异常检测中效果不佳。针对这一问题，本文围绕多节点的分布式集群时序异常检测展开研究，将分布式系统中的节点维度系统性地引入检测模型，利用集群内节点曲线应有的相似性特征，提出通过度量曲线偏离程度识别异常节点的算法。

针对单指标多节点异常检测中现有方法忽略节点间行为相似性、单一度量方法对阈值参数敏感的挑战，本文基于联通大数据生产环境的YARN集群监控数据构建了高质量的标注数据集，提出了CSAD-AT算法，融合欧氏距离、自编码器嵌入和密度聚类三种互补视角的曲线相似性评分，并引入改进的包容性SPOT算法实现阈值的动态自适应调整。实验结果表明，CSAD-AT算法的F1分数达到0.9864，较最优基线算法提升了43.1\%。

针对多指标多节点异常检测，本文提出了NSFusion数值与形状双视角融合的异常检测算法。面向多节点多指标下指标数量增长引起的效率挑战，框架采用轻量化的数值距离计算与无需训练的符号化形状度量相结合的方案替代单指标场景中计算开销较大的自编码器和密度偏离方法。面向多节点多指标下变化模式复杂对算法检测稳定性的挑战，本文在数值视角采用优化的基于欧氏距离的多指标加权融合方法量化节点间的数值差异；在形状视角提出全分辨率符号聚合近似算法，通过保留原始时间分辨率来提升对曲线形状变化的敏感性，弥补纯数值视角的检测盲区。在真实GPU集群故障数据集上的实验表明，双视角融合方法的异常节点检测准确率达到83.8\%，较最优单一视角方法提升了3.8个百分点，平均定位排名为1.18，两项指标均优于各项基线方法。

基于上述方法，本文设计并开发了基于曲线相似性的集群异常节点检测系统，采用前后端分离的四层架构，涵盖数据接入、检测引擎、常态化监控、告警管理和可视化看板五个功能模块。系统以模块化方式封装了全部检测算法，支持定时自动巡检和多级告警通知，具备对接生产环境监控体系的接口能力，单次巡检端到端耗时约20秒，满足分钟级巡检间隔的性能要求。

\intobmk\chapter*{Abstract}% 显示在书签但不显示在目录

Distributed clusters serve as the core infrastructure for cloud computing and big data processing, where operational stability is critical to business continuity. Existing time series anomaly detection methods mostly analyze monitoring data from temporal and feature dimensions. Due to the dynamic fluctuation of task loads in distributed clusters, time series metrics exhibit high randomness and large amplitude variations, resulting in poor performance of existing methods in multi-node anomaly detection. To address this problem, this thesis conducts research on multi-node time series anomaly detection for distributed clusters, systematically incorporating the node dimension into the detection model. By leveraging the inherent behavioral similarity among node curves within a cluster, algorithms are proposed to identify anomalous nodes through measuring the degree of curve deviation.

For the single-metric multi-node scenario, to address the challenges that existing methods neglect inter-node behavioral similarity and individual similarity metrics are highly sensitive to threshold parameters, this thesis constructs a high-quality labeled dataset from YARN cluster production monitoring data and proposes the CSAD-AT algorithm, which fuses curve similarity scores from three complementary perspectives, namely Euclidean distance, autoencoder embedding, and density-based clustering, and introduces an improved Inclusive SPOT algorithm for dynamic adaptive thresholding. Experimental results demonstrate that CSAD-AT achieves an F1 score of 0.9864, a 43.1\% improvement over the best baseline algorithm.

For the multi-metric multi-node scenario, this thesis proposes the NSFusion dual-perspective anomaly detection algorithm combining numerical and shape analysis. To address the efficiency challenges arising from the growth in the number of metrics, the framework replaces the computationally expensive autoencoder and density-based methods from the single-metric scenario with a lightweight combination of numerical distance computation and training-free symbolic shape measurement. To address the challenge that complex variation patterns pose to detection stability, the numerical perspective employs an optimized Euclidean distance-based multi-metric weighted fusion to quantify inter-node value differences, while the shape perspective introduces a Full-Resolution Symbolic Aggregate Approximation algorithm that preserves the original temporal resolution to enhance sensitivity to curve shape variations, compensating for the detection blind spots of the purely numerical perspective. Experiments on a real-world GPU cluster fault dataset show that the fusion method achieves an anomalous node detection accuracy of 83.8\%, a 3.8 percentage point improvement over the best single-perspective method, with an average fault localization rank of 1.18, outperforming all compared methods on both metrics.

Based on the above methods, this thesis designs and implements a curve similarity-based cluster anomalous node detection system with a four-layer front-back separated architecture, encompassing five functional modules: data ingestion, detection engine, routine monitoring, alert management, and visualization dashboard. The system encapsulates all detection algorithms in a modular manner, supports scheduled automatic patrol inspection and multi-level alert notification, and provides interfaces for integration with production monitoring systems. The end-to-end latency of a single patrol inspection is approximately 20 seconds, meeting the performance requirements for minute-level inspection intervals.
